# Полные тексты, часть 1

Отчёты 1–50 из 80. Предложение ИИ — черновик, решаете вы.

**Как размечать.** Откройте полный текст (путь или ссылка в блоке), сверьте предложение ИИ и допишите код в строку **Решение:**.

| Код | Что значит |
| --- | --- |
| `=` | согласен с ИИ |
| `+` | подходит: выборка (или подвыборка) употребляющих кратом, набранная не по проблемам с кратомом; мера расстройства или зависимости (DSM-5, DSM-IV, МКБ, KDS, SDS, LDQ, ASSIST, интервью); число или доля с порогом и знаменателем |
| `-1` | не подходит: обзор, комментарий, право или политика, протокол, качественное без подсчёта, кейс или серия кейсов, доклиника |
| `-2` | не подходит: выборка набрана по проблемам с кратомом (лечение КУД или абстиненции, отравления, неотложка) |
| `-3` | не подходит: не употребляющие кратом (фармакокинетика у здоровых) или другие виды Mitragyna |
| `-4` | не подходит: нет меры зависимости или расстройства для кратома (только доля употребления, мотивы, эффекты; или только абстиненция) |
| `-5` | не подходит: нет отдельной цифры для употребляющих кратом (только вся выборка или другое вещество) |
| `-6` | не подходит: порог по распределению самой выборки (медиана, верхняя треть, M + SD) |
| `-7` | не подходит: нет числа или доли с порогом и знаменателем (только средние, коэффициенты) |
| `-8` | не подходит: та же выборка, что в другом отчёте (связать) |
| `-9` | не подходит: другое — напишите почему |
| `?` | пока не решил (до закрытия файла нужно решить) |

Оценки ИИ брал из текста, но выписываться они будут на следующем этапе по оригиналу — здесь решаем только «подходит / нет» и причину. В исследованиях потребителей наркотиков, пациентов и студентов доля среди употребляющих кратом часто лежит в таблице по подгруппам.
